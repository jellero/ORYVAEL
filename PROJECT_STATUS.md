# Project Status

ORYVAEL is currently an architecture and reference-implementation project. It is not a production operating system.

## Present

- trust and authority model;
- human-governance constitution;
- capability authorization model;
- change classification;
- security invariants;
- AI-native SDLC;
- machine-readable schemas;
- Rust reference components;
- CI foundation.

## Not present yet

- bootable image;
- hardened system supervisor;
- production capability broker;
- immutable updater;
- hardware-backed roots;
- complete Linux sandbox integration;
- formal verification of implementation;
- Desktop/Mobile shells;
- production telemetry;
- signed artifact registry.

"Must" in architecture documents means a target requirement. Security guarantees require executable evidence; documentation alone is not evidence.
